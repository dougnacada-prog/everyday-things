A two-line explanation of a toaster for a 10-year-old: a jack-in-the-box for bread, then one honest sentence on what the analogy maps and what it leaves out. The program writes the entry (327 characters, two lines) to `/output/entry.txt`, checking it against the competition gate (1–400 characters, not only whitespace; exactly two lines) before writing.

## Run it

```sh
ENTRY_OUTPUT=./entry.txt node main.ts
```
